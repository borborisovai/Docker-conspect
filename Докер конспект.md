# Образы
Готовый к запуску "Образ" операционной системы.

### Dockerfile
Скрипт сборки образа, так-же может использовать другие образы для пересборки, или мультиступенчатой сборки
### Multi-Stage Build
Чаще всего используется при связки 2-х образов, в первом компилируется, во втором хостится. Нужно это чтобы итоговый образ не держал в себе балласт в лице полного пакета бесполезных программ 
### Тегирование
`<репозиторий>:<тег>` - В самом теге обычно указывают версию, или дату релиза, или кодовое имя релиза, или... Указывать туда можно что угодно, главное не запутать самого себя после этого 

# Контейнеры
Собственно в контейнере и происходят все действия. 

Множество контейнеров может обращаться к одному образу для экономии места на диске

Docker не является полноценной виртуальной машиной, поэтому часть компонентов заимствует у хост машины, что позволяет экономить ресурсы.

Однако это не запрещает держать в Docker полноценную виртуальную машину и/или Эмулятор.
### Архитектура
Docker поделён на 2 части.
- Docker Daemon (`dockerd`) - Собственно демон, внутри него всё и происходит.
- Docker CLI (`docker`) - Консольная утилита для управления Docker

### Команды
- `docker build` - создаёт образ из Dockerfile
- `docker images` - выводит список образов
- `docker pull` - загружает образ из репозитория (DockerHub по умолчанию)
- `docker push` - загружает образ в репозиторий (DockerHub по умолчанию)
- `docker tag` - локально устанавливает тэг для образа, для более простого поиска (Не разу им не пользовался, но судя из --help он делает именно это)
- `docker history` - показывает историю действий для каждого отдельного образа
- `docker run` - Запускает контейнер
- `docker ps` - выводит список контейнеров
- `docker stop` - останавливает контейнер
- `docker logs` - показывает историю действий для каждого отдельного контейнера.
- `docker exec` - Исполняет команду в контейнере
- `docker network` - Управление сетью

### Compose
Сложные программы, вроде сайтов, используют сразу несколько контейнеров. 
Compose позволяет настроить сложную структуру всего одним конфигом.
